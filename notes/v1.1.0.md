# Parkoid v1.1.0

Six Hypnotic Bleeps presets are available in the BLEEPS factory bank:

- Operator Drop: sequenced sine tones, no pitch envelope, two octaves lower than the original reference patch.
- Atonal Beacon: free-frequency FM modulator and slow timbre movement.
- Axis Spark: 7:1 FM with a fast pitch-envelope transient.
- Drift Choir: a gently drifting sine with velocity-sensitive decay.
- Sheffield Pulse: harmonic FM shaped by the amplitude envelope.
- Orbit Ping: stepped pitch and ping-pong stereo echoes.

The presets use Parkoid's existing synthesis architecture. Windows and macOS Universal installers include the VST3 plugin only. Existing user presets and parameter IDs are preserved.
